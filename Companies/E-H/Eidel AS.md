# Eidel AS

> Norwegian engineering company building secure data links, crypto distribution, telemetry and space instruments for defence and space.

## What they do

Eidel engineers secure communications, command and control, telemetry and space instruments for space, defence and critical infrastructure. Its defence solutions include secure data links, remote crypto key distribution, radio control and data acquisition, including missile telemetry. It has operated since 1966.

## Products and solutions

- **Secure Data Link** - Secure communications link
- **Remote Crypto Distribution System** - Remote crypto key distribution
- **Radio Control System** - Radio control for defence use
- **Distributed Data Acquisition System** - Telemetry data acquisition
- **Secure Satellite Link** - Space-segment secure link
